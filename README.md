# Zomato Dataset Analysis

## Overview
This project analyzes Zomato Bangalore restaurant data using Python and Machine Learning techniques. The project focuses on data preprocessing, exploratory data analysis (EDA), clustering, classification, and regression models to extract useful business insights.

---

## Objectives
- Clean and preprocess restaurant data
- Handle missing values and categorical features
- Perform exploratory data analysis
- Visualize restaurant trends and customer preferences
- Build classification and regression models
- Compare model performance
- Generate business insights from the dataset

---

## Results
- Random Forest achieved the best performance in both classification and regression tasks.
- Restaurant ratings were positively related to customer votes.
- Online ordering was widely supported among restaurants.
- Cluster analysis showed overlapping restaurant groups with limited separation.
